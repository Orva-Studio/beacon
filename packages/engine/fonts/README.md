# Fonts Beacon ships

The renderer registers every `.ttf`/`.otf` here for its own process (`beacon-render`'s `text.rs`), so captions and
callouts look the same on any Mac. Each is under the SIL Open Font License (`OFL.txt`), which allows bundling.
